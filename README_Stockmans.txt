# Calculadora de Economia — Stockmans

Aplicação Streamlit responsiva para comparar os custos de energia de:
- CLARK GTS30D (Diesel)
- CLARK GTS30L (GLP)
- CLARK L30XE (Elétrica)

## Rodar no computador

1. Instale Python.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Colocar online para abrir no celular

1. Crie um repositório no GitHub.
2. Envie `app.py` e `requirements.txt`.
3. Acesse o Streamlit Community Cloud.
4. Escolha o repositório e o arquivo `app.py`.
5. Faça o deploy.
6. Compartilhe o link gerado com o cliente.

O cliente não precisa instalar Python nem Streamlit: basta abrir o link no navegador do celular.
